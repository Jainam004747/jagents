# Git basics

Git is a distributed version control system. Every commit is a snapshot of the project identified by a hash, and branches are lightweight pointers to commits. The typical workflow is to edit files, stage changes with git add, record them with git commit, and share them with git push.

Branches let features be developed in isolation and merged back with a merge or rebase. Good commit messages explain why a change was made. Pull requests add code review before changes reach the main branch.
